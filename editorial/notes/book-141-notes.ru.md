## Правка 1: 68 случаев

Публичный источник числа 68 не называет: README на 763e024 говорит только о согласии вычислителей на прежнем корпусе из 66 векторов. Формулировка "исторический корпус 0.2.5" есть только в замороженной приватной копии. По условию задачи число убрано.

| Место | Было | Стало |
| --- | --- | --- |
| "Память агентов", таблица "Проверка / Результат" | строка "Дополнительные состязательные случаи \| оба вычислителя проходят все 68" | строка удалена; остались 66 смысловых векторов и неисполняемые 8 векторов развёртывания |
| "Где мы", строка "Проверка нормативного пакета двумя вычислителями" | "66 смысловых векторов и 68 состязательных случаев пройдены" | "66 смысловых векторов пройдены"; статус "работает сегодня" не менялся |

Не трогалось: `editorial/notes/status-ledger-part-2.ru.md` строка 53 сохраняет старую формулировку как запись прошлого прохода. Замечание вне задачи: публичный README на 763e024 называет пакет черновиком 0.3.0 с 85 векторами (77 смысловых, 8 развёртывания), а глава 15 и "Где мы" говорят о черновике 0.2.7 с 74 векторами по замороженному источнику; обновление версии пакета остаётся решением оркестратора.
