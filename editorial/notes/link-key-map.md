## Sources and limits

All implementation paths below are relative to the public laboratory repository. The map is role/custody guidance plus implementation facts, not a claim of automatic key rotation or host qualification. Cold name custody and keeping the landlord grant key separate from the owner's personal Nostr key are the requested deployment policy. The parser permits independent landlord social and grant keys, even equal public keys; the map does not falsely claim that parser equality is forbidden.
