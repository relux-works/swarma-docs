# Что находится в конверте

Формат — **`swarm-envelope/2`**, каноническая форма — **CCJ-1**. В Matrix конверт лежит в содержимом сообщения под именем **`works.relux.swarm.envelope`**.

| Поле | Что связывает проверка |
| --- | --- |
| `signer`, `key_id` | полную личность отправителя и конкретный удостоверенный ключ |
| `room`, `to` | комнату и полного адресата; не display name или короткий псевдоним |
| `ts`, `nonce` | время в допустимом окне и отсутствие повтора у проверяющего |
| `body_sha256` | SHA-256 точных байтов тела, которое увидел и подтвердил отправитель |
| `sig` | подпись ключа над установленным протоколом представлением |

**Учебный пример, не тестовый вектор.** Тело: `Удалить черновик «пример».` — UTF-8, без завершающего перевода строки. ID вымышлены, хэш вычислен, подпись — заглушка.

```json
{
  "works.relux.swarm.envelope": {
    "signer": "@operator:alpha.example",
    "key_id": "phone-example-key",
    "room": "!review:beta.example",
    "to": "@worker:beta.example",
    "ts": "2026-10-24T09:00:00Z",
    "nonce": "example-once-only",
    "body_sha256": "116b69bf4f07138497ff98a33fd51705c4f2645db2fe0daab0fb82d9a9d4b502",
    "sig": "EXAMPLE_NOT_A_SIGNATURE"
  }
}
```

Порядок полей и отступы — для чтения, не канонические байты. Нового поля версии или алгоритма пример не вводит.

1. План **Seraph S0** принимает **Ed25519** и **P-256/ECDSA с low-S**; алгоритм связан с аттестацией. Secure Enclave — P-256, агентский `swarma-msg` — Ed25519.
2. **Подпись: точная ASCII-метка без `0x0a` и управляющих байтов, затем `0x0a`, затем тело CCJ-1**. В S0 — закрытый список попарно различных платформенных меток. Проверяющий сравнивает метку побайтно до первого `0x0a`, без нормализации. Разделитель различает preimage разных меток, поэтому запрет префиксов для безопасности не нужен. Подпись одной роли или домена не принимается как подпись другой.
3. Ядро пересчитывает хэш тела. Получатель строит те же байты; подпись должна защищать назначение, время, nonce и хэш. Изменение тела требует новой подписи.
4. Кодировка подписи, вывод `key_id`, форматы времени и nonce, точный состав подписываемого тела, исключение `sig`, версия и ссылки на гранты ещё открыты. Их определяют контракт и общие векторы Seraph. Формат подписи регистратора сюда не переносится.
