# Что находится в конверте

Формат — **`swarm-envelope/2`**, каноническая форма — **CCJ-1**. В Matrix конверт лежит в содержимом сообщения под именем **`works.relux.swarm.envelope`**. Ни имя аккаунта носителя, ни визуальный текст клиента его не заменяют.

| Поле | Что связывает проверка |
| --- | --- |
| `signer`, `key_id` | полную личность отправителя и конкретный удостоверенный ключ |
| `room`, `to` | комнату и полного адресата; не display name или короткий псевдоним |
| `ts`, `nonce` | время в допустимом окне и отсутствие повтора у проверяющего |
| `body_sha256` | SHA-256 точных байтов тела, которое увидел и подтвердил отправитель |
| `sig` | подпись ключа над установленным протоколом представлением |

## Учебный пример, не тестовый вектор

Тело: `Удалить черновик «пример».` — UTF-8, без завершающего перевода строки. Полные ID вымышлены. Значение хэша ниже вычислено для этих байтов; подпись намеренно заменена текстовой заглушкой.

```json
{
  "works.relux.swarm.envelope": {
    "signer": "@operator:alpha.example",
    "key_id": "phone-example-key",
    "room": "!review:beta.example",
    "to": "@worker:beta.example",
    "ts": "2026-10-24T09:00:00Z",
    "nonce": "example-once-only",
    "body_sha256": "116b69bf4f07138497ff98a33fd51705c4f2645db2fe0daab0fb82d9a9d4b502",
    "sig": "EXAMPLE_NOT_A_SIGNATURE"
  }
}
```

Порядок полей и отступы выше — для чтения. Это не канонические байты. Форматы времени, nonce, ID ключа и кодировки подписи ещё должны быть закреплены спецификацией. Новое поле версии здесь не изобретается.

1. Ядро пересчитывает хэш тела и формирует подписываемое представление по CCJ-1 и контракту конверта. Key provider подписывает, получатель строит то же представление.
2. Назначение, время, nonce и хэш должны быть защищены подписью; иначе их можно подменить, сохранив подпись тела. Изменение одного байта тела требует нового хэша и подписи.
3. Точный preimage, доменная метка, правило исключения `sig`, версия и передача ссылок на гранты в предоставленном описании не заданы. Их определяет Seraph и общие векторы. По этой иллюстрации совместимую криптографическую реализацию писать нельзя.
