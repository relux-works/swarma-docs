# Уверенность и право действовать

Уверенность описывает свидетельство происхождения. Грант описывает разрешённое действие. Для допуска нужны **оба**, вместе со сроком, отзывом и совпадением цели. Высокий уровень не компенсирует отсутствующий грант.

| Уровень | Свидетельство | Граница действия |
| --- | --- | --- |
| A0 | отправителя утверждает homeserver | в целевом режиме — данные; в переходном — только заранее записанная зона названного человека |
| A1 | проверенное E2EE-устройство человека; в новой схеме также подпись агентского ключа | обычное общение; агентские сообщения остаются данными; критическое действие не разрешено |
| A2 | подпись человеческого ключа над точным конвертом, проверенная воротами по гранту | типизированное действие в пределах гранта; одного A2 недостаточно там, где нужно присутствие |
| A3 | телефон оператора показывает точное действие, человек подтверждает ключом | расширяющие действия: выдача грантов, привязки, допуски; иные критические действия по политике гранта |

## Как проходит проверка гранта

1. Найти зарегистрированное действие и конкретную цель; свободный текст не определяет новое полномочие.
2. Пройти цепочку до доверенного корня: подписи издателей, получатели, сроки, условия и отзыв. Каждое дочернее звено только сужает родительское.
3. Проверить требуемую уверенность и присутствие человека. Критичность задаёт грант, в том числе для release tags и удаления. Подтверждение привязано к точному действию, а не ко всему будущему разговору.
4. Повторить проверку на границе эффекта. Детерминированные ворота не спрашивают модель, достаточно ли убедительно сообщение. Дополнительный guard может только сузить допуск.

**Пример:** человеку разрешено читать отчёты; он присылает A3-подтверждение удаления. Уверенность достаточна, полномочия нет — отказ. Обратный случай: грант на удаление есть, но пришла обычная реплика из Element A1 — тоже отказ.

Лестница A0–A3 взята из книги. Новая схема разрешает аппаратное подтверждение также на Mac и FIDO-ключе, но точное отображение этих путей на A3 и формат свидетельства присутствия ещё надо закрепить. До этого их нельзя самовольно объявить эквивалентными телефонному A3.
