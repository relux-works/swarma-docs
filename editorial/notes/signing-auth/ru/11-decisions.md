# Как устроен Signer

Общее ядро Signer строит и проверяет конверты, цепочки аттестаций и гранты, а CLI `a2a` служит одним из его интерфейсов. Первым подключается адаптер Matrix, затем XMPP. Синхронизатор получает снимки отзывов, записи свежести и голову свидетеля, и детерминированные ворота выносят вердикт по ним; в сеть в момент вердикта ходит только онлайн-проверка критического действия. Приложения macOS и iOS встраивают ядро как framework на Relux Swift и Tuist, а секрет остаётся за провайдером ключа в Secure Enclave.

## Открытые вопросы

| Часть | Что осталось | Статус |
| --- | --- | --- |
| Формат `swarm-envelope/2`, срез v0 | Спецификация и офлайн-библиотека проверки; потребителей нет. | спецификация |
| Реестр и свидетель на узле доверия | Размещение, роли ключей и процесс подписи решены; службы нет. | решено |
| Запись свежести `freshness/1` | Решение и спецификация с офлайн-проверкой; публикации нет. | спецификация |
| Восстановление свежести | Спецификация; хранение истории и аудит не развёрнуты. | спецификация |
| Свежесть в других проверках | Приём старого снимка проверками аттестации, сообщения, гранта и действия; решение владельца. | открыто |
| Сертификация агентских ключей | 24 часа и доказательство публикации; подпись закрыта до реализации. | решено |
| Сервер свидетеля отката | Протокол предложен; транспорт и внешний хранитель открыты. | предложено |
| Провайдер A3 | Цель: P-256 в Secure Enclave на iOS; не квалифицирован. | открыто |
| Завершение отзыва | Барьеры, доказательство истечения и протокол онлайн-проверки. | открыто |
| Восстановление корня | Отдельное средство восстановления; следующая форма два из трёх. | решено |
| Запись восстановления, аккаунты носителя | Формат записи, аттестации master и OMEMO, первое закрепление. | открыто |
| Носители и другие владельцы | Бюджет события Matrix, адаптер XMPP, обмен реестрами. | открыто |
| Другие записи | WebAuthn, Ed25519-ключи FIDO, историческая проверка, экстренная остановка. | открыто |
| Язык ядра | Рекомендован Rust/UniFFI с Matrix Rust SDK; ревью не завершено. | предложено |
