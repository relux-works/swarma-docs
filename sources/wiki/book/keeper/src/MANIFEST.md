# Рисунки книги кипера: манифест

Каждый рисунок книги собирается из исходника PlantUML в этом каталоге. Рендер — `diagrams/<имя>.png`, его делает CI (`.github/workflows/keeper-book.yml`):

```
java -DPLANTUML_LIMIT_SIZE=16384 -jar plantuml-1.2025.4.jar -tpng -o "$PWD/book/keeper/diagrams" book/keeper/src/*.puml
```

Перед рендером CI запускает `book/keeper/check-figures.sh`: у каждой картинки из глав есть исходник и строка здесь, в `diagrams/` нет картинок без исходника.

**Происхождение.** «книга» — исходник ведёт книга; он следует §10.8 и направлению второй редакции, ссылки на разделы — в комментариях в начале файла.

**Статус** повторяет пометки книги (глава «Для кого эта книга»): «работает сегодня», «решено», «согласовано», «спецификация», «предложено», «вторая редакция» — направление второй редакции §10.8 по ревью первой.
