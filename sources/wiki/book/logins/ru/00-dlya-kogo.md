# Для кого эта книга

Вы запускаете Claude Code, Codex CLI или Muse через Curator, с рабочего стола, по ssh или в дочерних runs. В native home login есть, а агент отвечает «Not logged in». Эта книга объясняет, почему так бывает, где искать причину и какие команды уже можно использовать.

Короткий ответ: login принадлежит определённому store и определённому окружению. Папка конфигурации сама по себе не переносит доступ к Keychain. Claude на macOS различает desktop и ssh; Codex выбирает store через `cli_auth_credentials_store`; Muse по умолчанию использует глобальный Keychain. Curator отделяет источник authentication, выбор store и изоляцию home. Для Claude предложен отдельный setup-token path: executor передаёт env token, и login в каждом home больше не нужен. Сегодня работают измеренные native пути; удобные команды rc.7 решены, а CIP-0010 ещё Draft. ⟦работает сегодня⟧ ⟦решено⟧ ⟦предложено⟧

## Как читать статусы

Пометка относится к предшествующему утверждению или строке таблицы. «Решено» не обещает, что команда уже есть в установленной версии.

| Пометка | Что означает |
| --- | --- |
| ⟦работает сегодня⟧ | Измерено на названной версии либо работает в срезе rc.6 |
| ⟦решено⟧ | Решение принято или контракт нормативен; реализация может ждать rc.7 |
| ⟦предложено⟧ | Draft, которому ещё нужны нормативный текст и реализация |
| ⟦открыто⟧ | Не решено или не измерено |
