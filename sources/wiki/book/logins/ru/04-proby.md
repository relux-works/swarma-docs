# Что проверяли и чего опыты не обещают

Опыты 14 октября 2026 проводились на scratch OS users и scratch homes. Это позволяло отличить новый login от уже существующего, сопоставить файл и Keychain item и скрыть scratch credential file без изменения рабочего login. В книге сохранены результаты, а не credential output. ⟦работает сегодня⟧

| Инструмент | Версия и среда | Наблюдения |
| --- | --- | --- |
| Claude Code | 2.1.299, macOS 15 | desktop/ssh, отдельные stores, отсутствие login Keychain, env token, auth status |
| Codex CLI | 0.153.2 | native store setting и override `-c` |
| Muse | 1.4.8, macOS | global Keychain, отказ сохранения без него, explicit file, link, API key |

Для Muse facts pack указывает macOS без номера, а приложение с решениями уточняет macOS 27. Это уточнение относится только к Muse; переносить его на опыт Claude нельзя. Версии фиксируют границы наблюдений, а не обещают тот же результат после обновления.

## Положительный опыт рядом с отрицательным

У Claude удачный desktop login сопоставлен с `loggedIn=false` из ssh; удачный ssh file login — с «Not logged in» после скрытия файла. У Muse удачный explicit file login сопоставлен с missing credentials после скрытия файла; успешный OAuth без Keychain сопоставлен с провалом сохранения. Эти контрпримеры сужают утверждения до реально наблюдавшихся условий. ⟦работает сегодня⟧

Это не повторные тесты текущей установки и не доказательство всех вариантов OS, Keychain policy и session ancestry. Мы знаем, что конкретные stores не виделись в этих опытах. Из этого не следует, что можно безопасно менять store у уже работающей сессии. ⟦открыто⟧

## Что ещё не измерено

Refresh write behaviour не измерен, особенно для Muse с linked file. Не установлены гарантии concurrent refresh, atomic replace и сохранения link. D10 разрешает интеграцию до этих измерений, но решение не превращает неизвестное в измеренное. ⟦открыто⟧

Верификация книги проверяет Markdown, диаграммы, PDF и отсутствие запрещённых данных. Она не выполняет OAuth, не вызывает inference и не проверяет срок жизни credentials. Повторять auth-пробы следует в отдельных scratch окружениях.
