# Запись решения и воспроизведение

Каждое решение роутера записывается. Запись — не лог для отладки, а документ: по ней можно восстановить, что роутер знал, что выбрал и почему, и пересчитать выбор без сети.

## Что в записи

| Часть | Что хранит |
| --- | --- |
| входные данные | профиль задачи (включая исходный класс до перевода словаря), закрепки, контекст правил |
| кандидаты | допущенный набор и его источник: ответ доски, файл или `PATH` |
| каталог | действующий каталог после оверлея и дайджест оверлея |
| политика | полная политика с режимом бюджета |
| квоты | замороженная проекция остатков на момент решения |
| результат | выбранная конфигурация, альтернативы, причины, применённые и пропущенные правила |

Записи лежат в `$XDG_STATE_HOME/curator/model-router/decisions/`. ⟦работает сегодня⟧

## Идентификатор по содержимому

Идентификатор решения — дайджест SHA-256 канонического JSON записи: ключи отсортированы, умолчания материализованы, коллекции упорядочены по объявленному ключу. Тот же вход даёт тот же идентификатор; изменение одного бита входа даёт другой. Поэтому ссылка на решение указывает на одну неизменяемую запись. ⟦работает сегодня⟧

## Воспроизведение

Селектор — чистая функция от замороженных входных данных: без сети, файлов, часов и вызовов моделей. Повторный расчёт по записи даёт тот же выбор. Это даёт три вещи. ⟦решено⟧

- **Аудит.** Через месяц можно ответить на вопрос «почему эта задача ушла на эту модель», не гадая.
- **Проверку изменений.** Новую версию роутера или новые данные можно прогнать по старым решениям и посмотреть, что изменилось. Так мы проверили переход на публичную версию: 48 из 48 комбинаций роли, класса, сложности и бюджета дали тот же выбор.
- **Доверие к теневому режиму.** Если выбор можно повторить, расхождение с человеком — свойство данных и политики, а не случайность.

## Отказы

Отказ — тоже результат, и у него есть тип: `no_qualified_candidate`, `invalid_task`, `invalid_admission`, `invalid_policy`, `preflight_timeout`, `preflight_failed` и другие. Отказ никогда не притворяется выбором, а выбор по умолчанию никогда не притворяется решением роутера. ⟦работает сегодня⟧
