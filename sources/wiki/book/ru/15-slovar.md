# Словарь

Термины идут по алфавиту английского написания, как в спеках и командах. Пасечные имена — в карте имён главы 0.

| Термин | Что это |
| ----------- | ------------------------ |
| authority report, отчёт о полномочиях | отличия предлагаемой версии процесса от действующей: что покрыто правами и что ждёт человека |
| batched confirmation, подтверждение пачкой | одно касание подтверждает все накопившиеся изменения процесса |
| board, борда | трекер процесса в `.task-board/` репозитория; у людей — соты |
| capability, право | заранее выданное разрешение на вид изменений процесса, как разрешение приложения на телефоне |
| carrier | провайдер waggle, который доставляет подписанные конверты байт в байт |
| Change Request | неизменяемая опубликованная ревизия работы на ревью |
| check set, набор проверок | именованные команды проверки, которые идут локально, в CI или там и там |
| companion app, приложение-компаньон | приложение, которое показывает человеку, что он одобряет, и подписывает ключом в защищённом чипе |
| confirmation, подтверждение | запись, подписанная ключом с присутствием: человек принял версию процесса |
| delegation, делегирование | поручение действий человека его сессиям оркестратора в пределах доверенности |
| doorbell, звонок | короткое сообщение, которое session host вставляет в сессию, чтобы она сделала ход |
| dream, сон | репетиция процесса, где инструменты работают с `--dream` на копии борды |
| emergency stop, аварийная остановка | стоп-кран: снимок борд и остановка всех сессий и run'ов с возможностью продолжить |
| executor, исполнитель ядра | часть ядра, которая запускает инструменты и проверки вне процесса агента |
| guard | детерминированная проверка на переходе |
| guardrail / boundary | ограждение останавливает послушного агента, граница — и враждебного |
| hand-off, передача работы | состоянием владеет другой процесс, результат приходит событием `process.returned` |
| harness | программа, в которой работает агент: Claude Code, Codex, Muse, agy, Pi, Qwen |
| kernel, ядро | собственный код task-board, детерминированная часть без модели |
| lease | владение областью проекта со сроком и токеном, запись через compare-and-set |
| log distiller, дистиллятор логов | детерминированный инструмент, который убирает из логов шум и секреты, ничего не пересказывая |
| main loop, главный цикл | Кипер: постоянный цикл точки, который говорит с человеком и управляет ульями |
| managed home, управляемый дом | отдельный домашний каталог harness'а для профиля Curator |
| memory ladder, лестница памяти | память на нескольких уровнях подробности со ссылками вниз, до журнала |
| narrowing act, сужение | отзыв ключа, доверенности или права либо выключение инструмента; действует сразу |
| operator files, файлы оператора | личные TOML-файлы в `~/.curator/`: модели, runtime'ы, движки, сеть |
| owner, владелец | роль, которая отвечает за элемент в данном состоянии; ровно одна |
| park note, записка парковки | что сессия записывает при остановке; следующий старт читает её первой |
| playbook | роли, типы работ, переходы и политика процесса в `Playbook.json` |
| presence-bound key, ключ с присутствием | ключ, которым нельзя подписать без человека: FIDO2, Secure Enclave, TPM, приложение-компаньон |
| profile, профиль | в Curator — контекст, скиллы и MCP в lock, из которых собирается сессия |
| refuter, опровергатель | роль, которая ищет противоречия черновика с принятыми решениями |
| roster, ростер | файл `allowed_signers`: кто и что может подписывать |
| run | один запуск агента на задачу; у людей — пчела |
| session host | компонент, который держит сессии агентов в фоне: старт, цель, подключение, звонки |
| skill, скилл | пакет инструкций и команд для агента, который ставит Curator |
| standing answer, постоянный ответ | заранее данный оператором ответ на `ask` с ежемесячным ревью |
| tick | вызов ядра раз в минуту: таймеры, расписания, сроки, инструменты |
| version in force, действующая версия | последняя вступившая в силу версия процесса; её исполняет ядро |
| waggle | протокол подписанных сообщений между агентами |
| yolo | громкий явный режим, в котором изменения процесса вступают в силу без касания |
