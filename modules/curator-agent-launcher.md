# Лаунчер Curator

`curator-run` запускает явно выбранную среду через Curator и провайдера. [README][readme] различает поддерживаемые входы, экспериментальные маршруты и проект защищённого одноразового исполнителя. Отдельного скилла модуля в этой ревизии нет.

## Установка и запуск

README задаёт установку закреплённого тега компилятором из `go.mod`:

```sh
go install github.com/relux-works/curator-agent-launcher/cmd/curator-run@v0.6.0
curator-run --version
```

README ожидает версию `0.6.0` со спецификацией `0.5.1-draft` и называет совместимость с Curator v0.15.0-rc.3 или новее после публикации. Curator и желаемый провайдер устанавливаются отдельно. Точные аргументы запуска, требования среды и варианты релизных архивов находятся в разделах `Install and discovery` и `Launcher options`.

Матрица архивов включает Darwin и Linux для arm64 и amd64. Проверки контрольной суммы и подписи обязательны; у macOS дополнительно свои требования Developer ID и нотариального заверения. Матрица упаковки не квалифицирует каждый маршрут запуска.

## Ограничения

Контракт same-user non-chat не поставляет полный исполнитель или CLI допуска. Защищённый одноразовый запуск под отдельной учёткой остаётся целевым изменением. Нативный запуск и hosted-аренда дома имеют разные условия; один маршрут не подменяет другой. Исторический тег установки не удостоверяет все более поздние компоненты текущего `main`.
