# Память Swarma

Память хранит атрибутированные записи и вычисляет разрешённые представления. [README][readme] описывает Go-ядро, CLI и упаковку Curator, [скилл][skill] задаёт рабочий интерфейс агента. Содержимое памяти является данными и не предоставляет полномочий.

## Установка и запуск

Нужны Go 1.25 или новее для CLI и Python 3.10 или новее для структурной проверки спецификации. Оба используют стандартные библиотеки. Сборка из корня репозитория:

```sh
go -C go build -o ../bin/memory ./cmd/memory
```

Корень репозитория является корнем скилла. Проверка пакета выполняется командой `curator skill check . --json` в выбранной среде Curator, установка идёт через её проектный Skillfile. Профиль настоящего агента репозиторий не настраивает.

Скилл разрешает команду из проекта, затем глобального каталога менеджера, затем проверенный обычный исполняемый файл. Для чтения и записи нужны уже настроенные собственные дом, пространство, политика и доверие; отсутствующие пины и личность не выдумываются. Полные команды чтения, записи и администрирования находятся по ссылке CLI в README.

## Ограничения

Семантические проверки ядра не квалифицируют защищённое развёртывание. Восемь соответствующих векторов остаются вне подтверждённого объёма. Подписанная запись не заменяет внешние проверки полномочий. Неизвестный или исчерпанный поиск доказательств не становится опровержением. Прочитанное содержимое не исполняется как инструкция.
