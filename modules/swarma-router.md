# Маршрутизатор Swarma

Модуль содержит CLI `queued-task-handoff` для уведомления о задаче и отдельные Go-компоненты планирования и запуска. [README][readme] и [скилл][skill] отделяют их от проекта полного маршрутизатора.

## Установка и запуск

Для CLI нужны macOS или Linux, Go 1.23 или новее и уже настроенные `a2a` и `task-board`. Для файлового источника рабочего места нужен Go 1.23.0 и закреплённая `golang.org/x/sys v0.35.0`. Перед автономной сборкой необходим заполненный кэш точных зависимостей.

Сборка CLI из README:

```sh
mkdir -p .temp/bin
GOTOOLCHAIN=local GOPROXY=off go build -trimpath -o .temp/bin/queued-task-handoff ./cmd/queued-task-handoff
```

Запуск требует явных файлов запроса и частной политики и отдельного журнала. Сначала выбирается действие `plan`; оно читает источники и готовит уведомление без отправки. Полная команда и переход к отдельно разрешённому `dispatch` приведены в разделе `Queued task handoff` README. Примеры входов отказывают до замены на фактические допущенные значения.

## Ограничения

Уведомление в очереди не доказывает принятие задачи или начало работы. Автоматические Route, Apply и выбор модели отсутствуют; CLI рабочего места отсутствует. Библиотека запуска не подтверждает живой запуск. При неизвестном результате сохраняются исходные запрос, политика и журнал; новый журнал не служит способом повтора.
