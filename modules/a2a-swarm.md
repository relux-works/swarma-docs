# a2a

a2a предоставляет CLI координации через Matrix. [README][readme] описывает инструменты и соединения. [Скилл][skill] задаёт выбор установленной команды и правила собственной личности.

## Установка и запуск

Сначала определяется маршрут команды. В среде под управлением Curator используются команды проекта `.agents/bin/` или настроенного глобального каталога менеджера. Отсутствие команды в управляемой среде не разрешает переход к самосборке. Самосборная установка допустима только по отдельно разрешённому рецепту скилла, когда оба управляемых каталога отсутствуют.

Общая версия Go в корневом README не задана; точный компилятор и зависимости сверяются с выбранной ревизией модуля и рецептом установки. README содержит отдельные команды сборки и платформенные инструменты; это не универсальная процедура развёртывания.

После выбора собственной установленной команды справочники README и скилла описывают `whoami`, `rooms` и `inbox`. Нужны собственная настроенная личность, выбранное соединение и отдельно разрешённое членство. Учётные данные другого участника не служат входом. Само чтение скилла не разрешает регистрацию или отправку сообщений.

## Ограничения

Постановка сообщения, доставка уведомления и получение адресатом являются разными фактами. Связка с терминалом требует собственной живой сессии и поддерживаемого маршрута. Необязательный Keychain-помощник собирается на Darwin отдельно; README сохраняет запрет развёртывания этого изменения. Linux-проверки с подставными пробами не доказывают поведение macOS.
