# Контроль G07

Модуль допускает потребление управляющего события перед входом в исполнение. Он не вызывает хост. [README][readme] и [скилл][skill] описывают Linux Go API, а не службу.

## Установка и запуск

CLI и команды инициализации нет. Точка импорта: `github.com/relux-works/swarma-g07control`. API включает `Open(policyFD)` и `Consume(ctx, eventID, tokenFD)`; владение дескрипторами и точные требования изложены в скилле и его ссылках.

Нужны отдельно допущенная политика хранителя и уже закреплённое хранилище. Минимальная директива Go равна 1.26.0; README называет компилятор Go 1.26.10. Продукт использует стандартную библиотеку и системные вызовы Linux. Проверки требуют экспортированного изолированного стенда с `bwrap --clearenv --unshare-all`, исходниками и инструментами только для чтения, частными каталогами и пределами из README.

## Ограничения

Синтетическая политика не подтверждает допуск или исключительное владение исполнением. `INSPECTION_ONLY` не выдаёт полномочия повторно; только `NEWLY_CONSUMED` может рассматриваться хранителем для последующей разрешённой операции. Существующие записи после отказа сохраняются. Проверки не квалифицируют живое происхождение события, сохранность при потере питания или активацию исполнения.
