# Сайт Swarma

Статический сайт использует Astro и обычный CSS. Русские страницы первичны. [README][readme] и [скилл][skill] задают локальную разработку и проверки публикации.

## Установка и запуск

Нужны Node от 22.23.4 в пределах основной версии 22, npm, Python 3.12 и установленный Google Chrome для локальных браузерных проверок. CI использует Python 3.14 и закреплённый Playwright Chromium. Зависимости задаёт `package-lock.json`, `.nvmrc` выбирает Node 22.

Команды выполняются через внешний супервизор:

```sh
node scripts/run.mjs npm ci
node scripts/run.mjs npm run dev
node scripts/run.mjs npm run build
node scripts/run.mjs npm run check
```

`dev` запускает локальный сервер переднего плана; его останавливают после работы. Сборка пишет `dist/`, проверки и отчёты используют `.temp/`. Политика запрета идентификаторов предоставляется через отдельно настроенный вход из README; её неверное содержимое останавливает проверку.

## Ограничения

Сборка не заменяет полную проверку публикации и доступности. PR из форков пропускают CI, которому нужны недоступные им секреты, и остаются непроверенными на этом маршруте. Публикация PDF, рисунков книг, юридического текста и заявления о доступности сохраняет отдельные условия. Этот справочник не выполняет развёртывание сайта.
