# Диспетчер Swarma

Реализованный интерфейс ограничен Linux-транспортом отказа по вместимости и библиотеками кадров и допуска. Полный запуск остаётся проектом. Граница задана [README][readme] и [скиллом][skill].

## Установка и запуск

Для сборки нужен изолированный Linux-исполнитель и Go 1.26.10 с `GOTOOLCHAIN=local`. Команды проверок находятся в разделе `Tools and CI` README. Репозиторий не создаёт защищённую конфигурацию, UID, группы или каталоги сокетов.

Сборка двух точек входа:

```sh
go build -o .temp/swarma-dispatcher ./cmd/swarma-dispatcher
go build -o .temp/swarma-capacity ./cmd/swarma-capacity
```

Для отдельно квалифицированного развёртывания README задаёт запуск с единственным явным `--config` и абсолютным путём к соответствующей конфигурации сервера или клиента. Значений из окружения, подмены адреса и перечитывания конфигурации нет. Этот справочник не задаёт установку службы.

## Ограничения

Каждый корректный обмен возвращает `capacity:hold`; клиент завершает его кодом 2. Это ожидаемый отказ, а не разрешение запуска. Запуск агентов, журнал исполнения, восстановление и интеграция подписанных полномочий в этом транспорте отсутствуют. Нативное развёртывание не квалифицировано. Неизвестный исход сохраняет требования сверки и не доказывает отсутствие процесса.
