# Pulse

Pulse читает карточки продуктов и возвращает локальную проекцию участника. [README][readme] задаёт сборку, [скилл][skill] различает собственную карточку, объявленную среду и поиск связанных участников.

## Установка и запуск

Нужен Go 1.25.12 или более новый закреплённый компилятор; для ветки Go 1.26 требуется 1.26.5 или новее. Зависимость `go.yaml.in/yaml/v3 v3.0.5` закреплена в `go.mod` и `go.sum`. Общий установщик README не задаёт.

Сборка Pulse:

```sh
GOTOOLCHAIN=local go build -trimpath -mod=readonly -p 2 -o .temp/bin/pulse ./cmd/pulse
```

Форма чтения из README:

```sh
.temp/bin/pulse me --local-unsigned --card ABS --revision sha256:HASH --format json
```

`ABS` и `HASH` заменяются выбранным абсолютным путём и SHA-256 точных байтов карточки. Требуется собственный контекст `A2A_AGENT`; он не проверяется криптографически. Для поиска нужны также явно закреплённые локальные источники, как описано в скилле.

## Ограничения

Чтение не регистрирует учётку, не запускает сессию и не подтверждает установленный профиль. `pulse verify` отсутствует. Объявленная среда не доказывает состояние процесса. README указывает нативную проверку на macOS arm64; полноценная квалификация Linux и macOS имеет отдельные условия. Загрузка удалённой карты поиском не выполняется.
