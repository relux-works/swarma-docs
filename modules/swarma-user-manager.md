# Менеджер пользователей Swarma

Модуль содержит ядро станционных запросов, журнал поколений и Linux-компоненты. [README][readme] отделяет их от проекта полного привилегированного менеджера и лаунчера. [Скилл][skill] описывает границы действующих запросов.

## Установка и запуск

Для Linux-компонентов нужны Linux, Go 1.26 или новее и закреплённые зависимости. CI и отдельные проверки README закрепляют Go 1.26.10; NSS-помощнику дополнительно нужны cgo и C-компилятор.

Сборка станционной точки входа из README:

```sh
go build -o .temp/swarma-user-manager ./cmd/swarma-user-manager
```

Обычный помощник принимает один закрытый канонический JSON-запрос через stdin без аргументов. Названия операций спецификации не являются подкомандами CLI. Журнал проверяется отдельным инструментом; его сборка и входы находятся в разделе `Generation journal tools` README. Универсального установщика или исполняемого комплекта квалификации нет; процедура установки и пинов относится к владельцу.

## Ограничения

Производственное создание учёток и bump закрыты. Старые результаты на конкретной машине не квалифицируют другую установку. Реальные OS-backend и производственные адаптеры остаются неквалифицированными. Учётка `active` не означает разрешения запуска. Состояние процесса, поколение, владение и текущие полномочия проверяются отдельно; неизвестность не превращается в отсутствие процесса.
