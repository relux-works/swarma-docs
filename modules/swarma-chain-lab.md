# Лаборатория цепочки Swarma

Репозиторий содержит ограниченные исследования блокчейна. [README][readme] перечисляет эксперименты полных узлов, нотариуса, возраста UTXO и локального Namecoin Electrum. Скилл модуля в этой ревизии отсутствует.

## Установка и запуск

Общей программы, установщика или команды запуска нет. Каждый эксперимент расположен в `experiments/` и имеет собственный README с командами, версиями инструментов и условиями. Начинайте с соответствующей ссылки в корневом README.

Автономные проверки нотариуса используют стандартную библиотеку Python. Им нужны отдельное сетевое пространство без доступа наружу, исходники и инструменты только для чтения и частные HOME/TMP/кэш. Узел, кошелёк, данные живой цепочки и ключ не требуются. Корневой README не задаёт общую версию Python для всех экспериментов; требования одного опыта на другие не переносятся.

## Ограничения

Успех опыта подтверждает только его условия и проверки. Он не квалифицирует кошелёк, консенсус, службу, формат доверенности или развёртывание. Исторические помощники сохраняют истёкший предел допуска. Новый запуск требует собственного допуска изоляции и границ. Для отдельных опытов README сохраняет незакрытые условия адаптеров данных и независимого ревью.
