# Реестр владельцев Swarma

Модуль предоставляет компоненты допуска записей, хранения и проверки актуальности. [README][readme] описывает текущее состояние. [Скилл][skill] закреплён на более ранней ревизии; его интерфейсы требуют сверки с выбранным исходным кодом.

## Установка и запуск

CLI, сетевого слушателя и производственного адаптера публикации Git или свидетеля нет. Все реализованные пакеты находятся в `internal/` и предназначены для кода этого модуля. Общей команды установки службы нет.

README требует Go 1.26.10 и `gofmt`, с точными зависимостями модуля. Раздел `Tools` задаёт команды сборки и проверок компонентов и внешний ограничитель ресурсов. Он не поставляется как интерфейс реестра. Подготовка защищённых пинов, полной истории и независимых временных границ относится к вызывающему доверенному коду.

## Ограничения

Допуск кандидата, подтверждение вызывающего кода, локальная фиксация, внешнее разрешение и активация остаются разными результатами. Пропавшие данные не означают начало нового реестра. Операции с присутствием владельца, выбором ключа и подписью выполняются только при его участии. Предложения об активации владельца не создают вызываемого API.
