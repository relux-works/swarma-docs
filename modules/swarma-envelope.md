# Конверт Swarma

Модуль содержит чистые Go-библиотеки записей и проверки и автономные инструменты соответствия. [README][readme] и [скилл][skill] отделяют их от проектов транспорта, подписанта и работающего реестра.

## Установка и запуск

Точка импорта: `github.com/relux-works/swarma-envelope`; публичные пакеты включают `record`, `owneracts` и `verifier`. Нужен Go 1.26.0 или новее. README называет проверенный Go 1.26.10 через `CURATOR_GO`, Python 3.14.4 и уже установленную cryptography 46.0.5 для независимой проверки P-256. Это зафиксированная проверенная среда, а не разрешение обновлять зависимости. Единой команды установки службы нет.

Для Go API вызывающий код предоставляет защищённые снимки явно. У автономных инструментов собственные команды из ссылки `offline tooling` в скилле. Они работают с опубликованными векторами; этот справочник их не запускал. Автоматической загрузки доказательств, неявных часов и регистрации плагинов у чистого проверяющего нет.

## Ограничения

Неподписанное предложение, математически корректное подписанное намерение и кандидат плана транзакции имеют разные значения. Нативное хранение, присутствие владельца, актуальность прав, долговечная история, защита от повтора и эффекты потребителя остаются внешними обязанностями. Проверка не выдаёт разрешение подписи или исполнения. Исторический SSHSIG-проект не является реализованным платформенным транспортом.
