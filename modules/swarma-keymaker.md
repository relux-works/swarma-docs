# Ключник Swarma

Ключник содержит Linux-ядро хранения, нативную интеграцию и локальные компоненты зачисления. [README][readme] сохраняет отдельные условия публикации и квалификации. [Скилл][skill] выделяет публичный кодек `stationcaller`.

## Установка и запуск

Нужны Linux, Go 1.26.10 и точные зависимости из `go.mod` и `go.sum`. Рецепт сборки релиза и проверка артефакта находятся по ссылке `v0.1.0 linux/amd64 build and verification` в разделе `Tools` README. Этот рецепт не устанавливает и не активирует службу.

Для публичного кодека скилл задаёт:

```sh
go build ./stationcaller
```

Это компиляция пакета, без транспорта и подписанта. Для службы README отдельно описывает сборку `cmd/keymaker`, команды `version` и `serve --config`, защищённые входы и проверку готовности. Конфигурация службы не заменяется данными примера.

## Ограничения

Кодек переводит типизированные запросы и ответы в байты. Разбор публичного ключа или подписи не проверяет происхождение и полномочия. Purpose 6 и оба нативных метода station-caller остаются выключенными до закрытия опубликованных условий квалификации. Наличие константы не регистрирует рабочий метод. Подстановка читаемого ключа или произвольной подписи не служит обходом.
