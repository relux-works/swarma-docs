# Хост сессий Swarma

Репозиторий содержит прототип хоста и исполнителя переднего плана. Хост хранит намерения ввода и квитанции; исполнитель владеет дочерним процессом и его потоками. Граница описана в [README][readme] и [скилле][skill]. Скилл указывает более раннюю доказательную ревизию.

## Установка и запуск

Нужны Go 1.25.5 и Python 3. На macOS наблюдатель процессов и проверки гонок используют cgo и Apple C toolchain. Без Darwin/cgo наблюдатель явно сообщает об отсутствии поддержки.

Сборка из README выполняется на macOS:

```sh
mkdir -p .temp/prototype/bin .temp/prototype/evidence
GOTOOLCHAIN=local GOWORK=off go build -p 1 -o .temp/prototype/bin/ ./cmd/...
```

Точные команды синтетического запуска и управления находятся по ссылке `Commands and verification` в скилле. Они требуют частного состояния и явных конвертов управления. Универсальная установка службы не описана.

## Ограничения

Текущие адаптеры включают JSON/строчные примеры и Codex 0.164.0. Claude и Muse представлены только примерами интерфейса. G07 и потребление грантов недоступны. Управление целями зарезервировано и отказывает; реальная hosted-интеграция отсутствует. Сокет одного UID не изолирует агентов общего пользователя. При неизвестном вводе сохраняются исходные исполнение, состояние и квитанции без повторной отправки.
