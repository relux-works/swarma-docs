# Регистратор Swarma

Регистратор проверяет доказательства регистрации и выдаёт JWT через HTTPS-службу. [README][readme] задаёт запуск, [скилл][skill] различает публичные Go-библиотеки и служебные адаптеры.

## Установка и запуск

Нужны Go 1.26.10, Git и OpenSSH. Сборка из корня модуля:

```sh
go build ./cmd/registrar
```

Раздел `Run the registrar` README задаёт `registrar serve` с явным `--config`. Перед запуском требуются защищённая конфигурация, сертификат и ключ HTTPS, подписанный закреплённый источник реестра, хранилище верхней границы, PKCS8-подписант JWT и долговечная цепочка аудита. Они не создаются сборкой. Справочник конфигурации и процедура сверки при старте находятся там же.

## Ограничения

`GET /readyz` возвращает 503 до установки проверенного снимка и допуска времени, подписанта и аудита. Флаг тестового HTTP разрешает только буквальный loopback и не отменяет эти проверки. Переключателя здоровых часов нет. Без доступного аудита выдача отклоняется. Успех проверки доказательства отдельно не подтверждает аудиторию, свежесть, отсутствие повтора или разрешение зачисления. Живой помощник брокера относится к другому модулю.
