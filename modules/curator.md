# Curator

Curator управляет пакетами скиллов, зависимостями, командами и средами агентов. [README][readme] содержит способы установки и справочник команд. Отдельного скилла самого модуля в этой ревизии не найдено; скиллы в тестовых данных не служат руководством установки.

## Установка и запуск

Раздел `Install` README описывает Homebrew для macOS/Linux, проверяемый установщик, Scoop для Windows, Go и пакеты релиза. Скрипту установки нужен GitHub CLI или cosign для проверки происхождения, подписи и контрольной суммы. Ссылка на плавающую ветку или `@latest` не закрепляет устанавливаемые байты; для воспроизводимой установки требуется отдельно выбранный проверенный релиз. Обход проверки целостности здесь не предлагается.

Разделы `Commands` и `Commands without profile setup` описывают настройку проекта, установку пакетов и `curator run`. Нужны явно выбранные профиль и среда и их собственные зависимости. После установки команды проекта доступны через `.agents/bin/` на Unix и соответствующие `.cmd` на Windows; изменение профиля оболочки не обязательно.

## Ограничения

Установка среды не подтверждает вход к провайдеру. Для Claude Code на macOS README требует отдельный вход в каждый управляемый дом до первого запуска. Наличие пакета, плана или командного адаптера не заменяет допуск исполнения. Команды обновления меняют выбранное замыкание зависимостей и не являются способом сохранить неизменную ревизию.
