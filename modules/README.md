# Справочник модулей Swarma

Каждая страница ведёт к установке, запуску и ограничениям одного модуля. Ссылки на README и скиллы закреплены на коммитах публичной ветки `main`, прочитанных 7 ноября 2026 года. Это справочник исходного кода. Наличие кода в `main` не подтверждает установленную команду, допуск или проверку работающей службы.

Команды сборки выполняются из корня соответствующего репозитория, если страница не задаёт другой каталог. Версии инструментов и зависимостей берутся из указанной ревизии. Примеры требуют собственных допущенных входов; они не создают полномочий. Справочник проверен по текстам без запуска модулей.

## Покрытие и пробелы

В справочник включены 24 публичных репозитория с содержимым в `main`. Для каждого есть отдельная страница и ссылка на точную версию. a2a, конверт и память включены как прямые источники документации и зависимостей модулей. Это перечисленный набор, а не утверждение о полноте всех репозиториев платформы.

В корне репозитория доски README отсутствует; её страница опирается на два скилла и README поставщика данных. У Curator, его лаунчера, хоста продукта и лаборатории цепочки отдельный скилл модуля не найден; примеры скиллов в тестовых данных им не заменяют. Эти пробелы указаны на страницах.

`swarm-network-proxy` исключён: публичные README и скилл для этой проверки недоступны. Закрытые исходники и рабочие сведения в справочник не переносились. Другие репозитории и ветки вне перечисленного набора не проверены. Ни одна страница не добавляет установщик, команду активации или подтверждение поддержки платформы сверх указанного источника.
