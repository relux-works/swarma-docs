# Документация Swarma

Репозиторий хранит русские книги и пейперы. Русская версия служит источником правды. Если книга или пейпер расходятся со спецификацией модуля, расхождение поднимается к владельцам и решается в каждом случае отдельно; до решения права книга Swarma; у книги об a2a своё правило старшинства. [README][readme] содержит карту текстов и инструментов, [скилл][skill] описывает редактуру.

## Установка и запуск

Единой службы и общей команды установки нет. Для редактуры достаточно исходников и проверки гигиены:

```sh
sh scripts/check.sh
```

Она требует подходящую UTF-8 locale, проверяет тексты шести книг и пейперов и возвращает ненулевой код при блокирующем нарушении. Эта проверка не доказывает факты; новые тексты вне её области требуют отдельной сверки.

Для сборки книги README называет pandoc 3.x, WeasyPrint 69+, Graphviz 14.0.4 для прохода рендера и шрифты PT Serif, PT Sans и PT Mono. Пейпер использует tectonic 0.17. У отдельной записки о подписях закреплён собственный platform-book. Точные команды и выходные файлы находятся в таблице `Инструменты`; требования разных текстов не объединяются в один выдуманный установщик.

## Ограничения

Пишущий участник редактирует Markdown и LaTeX. PDF и диаграммы собираются отдельно после ревью. Редакторская проверка не публикует сайт, не выпускает PDF и не подтверждает работу платформы. Существующие главы состояния остаются источником статусов книг.
