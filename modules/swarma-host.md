# Хост продукта Swarma

Репозиторий хранит желаемую карточку продукта `product-card/product-card.yaml` формата `product-card/v3`. [README][readme] описывает чтение через Pulse. Скилл модуля в этой ревизии отсутствует.

## Установка и запуск

Самостоятельной программы или команды установки хоста README не задаёт. Нужен проверенный Pulse с поддержкой вида среды, начиная с указанной в README ревизии или совместимого преемника. Полная команда в разделе `Tools` вычисляет SHA-256 выбранной карточки через `shasum` и вызывает `pulse me --local-unsigned --view environment` с явными `--card`, `--revision` и `--format json`.

Сохраняется собственный контекст `A2A_AGENT`. Чтение выводит JSON и не меняет карточку. Сборка Pulse и его требования описаны на [странице Pulse](swarma-pulse.md).

## Ограничения

Карточка задаёт желаемые назначения, профили и координаты запуска. Она не удостоверяет работающий процесс и не предоставляет доступ. `state: complete` означает полноту объявленных полей; наблюдения исполнения остаются неизвестными. Реестр публичных ключей и общий загрузчик конфигурации ожидают реализации и согласования.
