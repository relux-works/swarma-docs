# Брокер учётных данных Swarma

Опубликованы экспериментальное Linux-ядро демона, исполнитель и автономные компоненты проверки. [README][readme] сохраняет закрытые условия выдачи и релиза. [Скилл][skill] описывает более раннюю базовую ревизию; его ссылки требуют повторной сверки с текущим кодом.

## Установка и запуск

Демону нужен Go 1.25 или новее. Проверки разработки в README используют Go 1.26.10 через `CURATOR_GO` и `GOTOOLCHAIN=local`. Точные зависимости закреплены модулем; компонент владельца добавляет `github.com/godbus/dbus/v5 v5.1.0`.

README задаёт сборку:

```sh
go build -o ../.tmp/swarma-credential-broker ./cmd/swarma-credential-broker
```

Выходной каталог должен быть выбранным частным рабочим каталогом. Раздел `Daemon configuration and current boundary` описывает защищённую статическую политику, хранилище, допуск по ядру и фактические ограничения. Скрипт миграции имеет проверки на изолированных данных; для реального развёртывания нужны интеграции и квалификация из отдельного руководства. Общего разрешения установки из сборки не следует.

## Ограничения

Поставляемый адаптер владельца отказывает в выдаче, производственный набор квалифицированных релизов пуст. Режим без секретов не активирован. Операции с учётными данными, хранением, зачислением, обновлением и подписью требуют присутствия владельца. Статическая allowlist-наблюдаемость не является арендой или разрешением запуска. Библиотечный результат не даёт разрешения на живой вызов.
