# Большие файлы и память сети

Алиса записала видео о своём саде. Оно не поместится ни в какую транзакцию, поэтому файл живёт в сети BitTorrent: это обычная раздача, где участники передают части файла друг другу. В короткую запись помещается ссылка magnet первой версии. Она содержит infohash, хэш метаданных раздачи, а метаданные содержат хэши частей файла. Клиент скачивает файл и сверяет части с метаданными, поэтому посторонний раздающий не может незаметно подменить содержимое. Отдельный хэш файла SHA-256 вместе с такой ссылкой в выбранные 77 байт не помещается. Его можно записать вместо ссылки, но сам хэш не указывает, где скачать файл, и глава "Где мы" отмечает способ их связать как открытый.

В системе доверенностей полный документ тоже лежит вне цепочки. Грант хранит полномочия, контракт содержит согласованные условия, а печать позволяет прекратить доступ тратой выхода. Обязательство выдачи связывает точный подписанный грант с записью в цепочке; его формат разобран в книге о Swarma Link. Страница, Markdown или видео может быть чем угодно, а логика проверки одна. Клиент показывает скачанный Markdown и HTML так, чтобы они не могли выполнить чужой код.

У Swarma Link есть отдельный локатор LIP-0005: идентификатор протокола `SL`, действие, версия, обязательство и типизированный указатель. Хранилище Blossom использует SHA-256 объекта; BitTorrent использует хэш метаданных раздачи. Эти указатели относятся к разным байтам. Идентификатор Memo `0x6d` и его текстовое действие `6d02` сохраняют свой формат. Локатор Link не задаёт нового значения для текста поста Memo и не закрывает вопрос получения файла по произвольному текстовому хэшу.

Кто раздаёт файл? Сначала автор. Затем те, кому интересно: популярное видео раздают многие, поэтому обычно оно живёт дольше. Лайк может включать раздачу по настройке клиента, хотя сам по себе лайк места на диске не занимает. Кому нужно надёжнее, платит узлу за хранение на срок: это услуга рынка узлов с названным сроком и числом копий.

Доступность файла зависит от тех, кто его раздаёт, и может прерываться. То, что важно многим, с большей вероятностью сохранится, а остальное может потеряться, и это приемлемо. Популярность гарантии не даёт: в исследовании 2009-2010 годов примерно 46000 раздач 38% стали недоступны в первый же месяц, причём некоторые раздачи без полных копий всё равно завершались из разрозненных частей. Эта работа описывает другие годы и другую сеть, поэтому прогнозом для нашей сети она не служит. Клиент говорит то, что знает: файл есть у меня, файл доступен у таких-то узлов на такое-то время, файл доступен частично, файл сейчас недоступен и в цепочке осталась ссылка.

Браузер работает с BitTorrent через WebTorrent, поверх WebRTC. Обычная веб-страница не имеет сырых сокетов, поэтому ей нужен раздающий узел с поддержкой WebRTC и служба сигнализации. На настольном клиенте работает обычная библиотека libtorrent. Закрытые файлы из Swarma Talk шифруются до раздачи и публичными не становятся.

Если Алисе важно сохранить видео, она оплачивает хранение.
