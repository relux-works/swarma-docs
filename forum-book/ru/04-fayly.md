# Большие файлы и память сети

Алиса записала видео о своём саде. Оно не поместится ни в какую транзакцию, поэтому файл живёт в сети BitTorrent: это обычная раздача, где участники передают части файла друг другу. В цепочку попадает текстовая ссылка magnet, а для проверки файла ещё и его хэш, как показывает глава "Публичная запись". Клиент скачивает файл и сверяет его с хэшем. Подменить содержимое незаметно нельзя.

Устройство такое же, как у доверенностей: документ лежит вне цепочки, а его отпечаток в цепочке. Страница, Markdown или видео может быть чем угодно, а логика проверки одна. Клиент показывает скачанный Markdown и HTML так, чтобы они не могли выполнить чужой код.

Кто раздаёт файл? Сначала автор. Затем те, кому интересно: популярное видео раздают многие, поэтому обычно оно живёт дольше. Лайк может включать раздачу по настройке клиента, хотя сам по себе лайк места на диске не занимает. Кому нужно надёжнее, платит узлу за хранение на срок: это услуга рынка узлов с названным сроком и числом копий.

Доступность файла зависит от тех, кто его раздаёт, и может прерываться. То, что важно многим, с большей вероятностью сохранится, а остальное может потеряться, и это приемлемо. Популярность гарантии не даёт: в исследовании 2009-2010 годов примерно 46000 раздач 38% стали недоступны в первый же месяц, причём некоторые раздачи без полных копий всё равно завершались из разрозненных частей. Эта работа описывает другие годы и другую сеть, поэтому прогнозом для нашей сети она не служит. Клиент говорит то, что знает: файл есть у меня, файл доступен у таких-то узлов на такое-то время, файл доступен частично, файл сейчас недоступен и в цепочке осталась ссылка.

Браузер работает с BitTorrent через WebTorrent, поверх WebRTC. Обычная веб-страница не имеет сырых сокетов, поэтому ей нужен раздающий узел с поддержкой WebRTC и служба сигнализации. На настольном клиенте работает обычная библиотека libtorrent. Закрытые файлы из Swarma Talk шифруются до раздачи и публичными не становятся.

Хэш в цепочке сохраняет доказательство, а хранить файл должен кто-то живой. Если видео Алисы важно ей самой, ей стоит оплатить хранение.
