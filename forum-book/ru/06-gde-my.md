# Где мы

Эта книга описывает Swarma Forum в завершённом виде. Этот раздел единственный, где сказано, что существует на самом деле. Сервиса нет, индексатор для Namecoin не написан.

| Часть | Что это | Статус |
| --- | --- | --- |
| Протокол memo на Namecoin, набор действий | Принятое направление: берём как есть. Коды взяты из открытого индексатора `memocash/index@9dec1940`. Переноса на Namecoin нет. | решено |
| Профиль совместимости: автор, входы, размеры, порядок байт | Не опубликован. Описан только начальный профиль P2PKH с пределом 83 байта. | открыто |
| Размер `OP_RETURN` | Расчёт по исходному коду: 83 байта у Core 28, около 100 000 у версии 32. Что принимают майнеры, не измерено, замер запланирован. | открыто |
| Текстовая запись хэша и способ получения файла | Хэш в шестнадцатеричном виде помещается в пост. Правило получения файла по нему не определено. Отдельный локатор Link с идентификатором `SL` не меняет текстовый формат Memo. | открыто |
| Цены и ёмкость | Расчёт при указанных допущениях, без реальных транзакций. | открыто |
| Индексаторы и разные представления | Предложенное устройство. | предложено |
| Обращение с оплатой | Принятое направление. Сквозной работы нет. | решено |
| Формат обращения с оплатой | Не выбран и не опубликован. | открыто |
| Большие файлы через BitTorrent | Компоненты существуют, наша сборка не делалась. | предложено |
| Вторая дорожка с корнем Меркла | Предложено на случай роста. | предложено |
| Правовой статус операторов | Требует консультации юриста до публичного запуска. | открыто |

Порядок работы такой: сначала доверенности на настоящем Namecoin и замер размера `OP_RETURN`, затем обмен сообщениями. Forum опирается на результаты замера и следует за ними. Мы изучили ранние работы других проектов и используем их как основу: memo.cash и Member показывают, что такая модель работает на практике.
