# Где мы

Эта книга описывает Swarma Talk в завершённом виде. Этот раздел единственный, где сказано, что существует на самом деле. Мессенджера нет: ни настольного, ни мобильного.

| Часть | Что это | Статус |
| --- | --- | --- |
| Уведомление BIP47 и производные идентификаторы | На regtest настоящая транзакция уведомления на 80 байт дала получателю платёжный код, а экспериментальный вывод ключей ящика совпал у обеих сторон. Этот вывод не входит в BIP47. Анонимность, прямая секретность и встроенная поддержка в Namecoin Core не заявляются. | проверено на regtest |
| Обмен через два локальных сервера | Получен отчёт о лабораторном опыте; результат требует независимой проверки. | предложено |
| Документ личности, адрес узла для первого запроса, передача на очереди получателя | Описание механизма. Формат не определён и не опубликован. | открыто |
| Контакт вне цепочки | Принятое направление. Сквозной работы нет. | решено |
| Обращение с чаевыми | Принятое направление. Сквозной работы нет. | решено |
| Слепые ящики, четыре состояния сообщения | Принятое направление. Служба не написана. | решено |
| Права записи в очередь, формат и передача | Не определены и не опубликованы. | открыто |
| Подписка на адрес узла, бесплатные ящики на старте | Принятое направление. Сквозной работы нет. | решено |
| Два формата переписки | Принятое направление. Конкретная реализация не выбрана. | решено |
| Схема обновления ключей, профиль личных разговоров, анализ отрицаемости всего обмена | Кандидат на личные разговоры: семейство протоколов Signal. Анализ с транспортными подписями и квитанциями не проводился. | открыто |
| Сообщения как события Nostr, два релея | Пилот запланирован после эксперимента с доверенностями. Для пилота нужно проверить восстановление, авторизацию и передачу вложений. | предложено |
| Привязка ключа Nostr к личности и место публикации этой связи | Кандидаты: отдельная аттестация, ключ в значении имени с общим сидом. Форк Nostr допустим. | открыто |
| Основа клиента | Buzz, клиент с общими комнатами для людей и агентов на собственном релее, предстоит проверить в деле. Там один авторитетный сервер, и это учитывается в проверке. Цель: человек скачивает клиент и начинает работать без регистрации на сервере. | открыто |
| Группы на MLS | Код не выбран, кандидаты изучены только по исходному коду. | предложено |
| Звонки | Компоненты существуют, наша сборка не делалась. | предложено |
| Журнал контактов и восстановление | Описано сейчас, реализуется позже. | решено |
| Повторная отправка неподтверждённых сообщений для нового устройства | Предлагаемое поведение. Зависит от исходящей копии у отправителя и срока хранения. | предложено |
| Форматы контакта вне цепочки, обращения с чаевыми, журнала контактов и описания восстановления; правила подтверждения и возврата средств у подписки | Не определены и не опубликованы. | открыто |
| Организация в сервисе, архив и боты как видимые участники | Принятое направление. Нужен проверочный набор. | решено |
| Телефоны и узлы уведомлений | Вне первой версии, которая работает на настольных компьютерах. Настоящие устройства не проверялись. | предложено |
| Рынок узлов | Тезис принят. Экономика и производительность не измерены. | решено |
| Почтовая демонстрация смены сервера | Подготовка в лаборатории на regtest, настоящая почта не отправлялась. | открыто |
| Самостоятельные агентские сущности, которые держат узлы | Отдельное описание ожидается. | открыто |

Цифры о трафике и ёмкости это расчёты при указанных допущениях. На настоящих устройствах и в настоящих сетях мы ничего не измеряли.

Порядок работы: сначала доверенности на настоящем Namecoin, затем пилот на двух релеях с агентами внутри системы доверенностей, затем почтовая демонстрация и узлы. Подробности в главе "Где мы" книги о Swarma Link.
