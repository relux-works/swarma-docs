# Звонки

Алиса звонит Шляпнику. Приглашение идёт по уже защищённому каналу их контакта, поэтому посторонний не может притвориться Шляпником и перехватить разговор. Сам разговор идёт по другому пути, потому что голосу нужна низкая задержка.

Для передачи голоса и видео мы берём WebRTC, существующий стек с шифрованием и подавлением эха. Сначала клиенты пытаются соединиться напрямую. Большинство устройств сидит за маршрутизаторами, которые не пропускают входящие соединения, и здесь помогает ICE: клиенты перебирают возможные пути. Сервер STUN подсказывает клиенту его внешний адрес. Если прямого пути нет, например из-за строгого корпоративного файрвола, разговор идёт через сервер TURN, который просто пересылает зашифрованный поток.

Прямой звонок раскрывает собеседникам адреса друг друга. Режим только через TURN скрывает их друг от друга, но тогда адреса и объём трафика видит сам TURN. Содержимое он не читает.

Пересылка стоит денег. Для примера: разговор с потоком 64 кбит/с в каждую сторону через такой сервер это около 58 МБ в час на выходе, а видео по 1 Мбит/с около 900 МБ. Тысяча одновременных видеозвонков это примерно 2 Гбит/с. Это счёт, который кто-то оплачивает: на старте мы, затем подписчики этой услуги или организация для своих сотрудников.

Скайповских суперузлов из чужих компьютеров здесь нет. Трафик пересылают только узлы, которые сами на это согласились: провайдеры и организации. Компания, которая держит постоянно работающий узел для своих людей, тем самым делает всю сеть менее зависимой от любого одного оператора.

## Групповые звонки

При разговоре нескольких человек прямые соединения быстро перегружают канал, поэтому поток идёт через сервер, который раздаёт его участникам. В Nostr для таких голосовых и видеокомнат уже описана связка с LiveKit. Если такому серверу не доверять, шифрование добавляется на уровне участников, и это отдельный стандарт SFrame. Без него сервер видит содержимое. Клиент показывает, какой режим включён.

Клиент показывает "соединено" только тогда, когда голос идёт в обе стороны. Подтверждённое приглашение этого не означает.
