# Группа и её ключи

Группа объединяет разрешённые устройства нескольких участников. В комнате обсуждения клиент показывает людей, но шифрование должно учитывать каждый их ноутбук и телефон. Один человек с двумя устройствами создаёт две точки доступа к содержимому.

Для защиты группового обмена служит MLS, Messaging Layer Security, протокол согласования ключей группы. Эпохой называется состояние группы с определённым составом устройств и ключами. Например, после добавления нового устройства участники принимают следующую эпоху и посылают новые сообщения с её защитой. Приложение отдельно проверяет, кто вправе добавить это устройство: MLS не знает правил организации.

Изменение состава требует завершённого перехода ключей. После отзыва устройства новые конфиденциальные сообщения отправляются только в эпоху без него. Если разрешённый участник, который завершает переход, недоступен, затронутая комната приостанавливает новые отправки. Продолжение в старой эпохе сохраняло бы доступ исключённого устройства.

Правила истории определяют, что получает новичок. Доступ к будущим сообщениям не даёт автоматически ключей от прежней переписки. Организация может явно открыть выбранную историю, если сохраняет её и имеет право передать. Личная группа может оставить прошлые сообщения только прежним участникам.

Удалённый участник сохраняет уже полученные сообщения и ключи. Отправитель, который не узнал об отзыве, может продолжить писать в старую эпоху. Поэтому граница защиты проходит по принятому изменению полномочий и завершённой смене ключей у отправителя. Сервер не может отозвать память собеседника или предотвратить передачу текста действующим участником.
